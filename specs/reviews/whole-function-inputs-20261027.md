## Mechanism

Complete registered Hom owners take precedence over a function projection. Their
full category, scalar structures and endpoints remain selected. Only a checked
Sets context permits its declared data-field projection. Whole-callable point
construction retains actual packets, every opaque supplier and constituent service
operands; its formal constant point supplies only the independently selected type.

Admission keeps its outer point domain separate from the callable's internal
domain. A different declared global domain uses its actual registered comparison,
with both complete endpoint fragments checked. An ordinary composition is marked
framed after consuming those actions, with no fabricated unframed origin. A
changed comparison requires genuine producer provenance. Observation uses the
existing whole-point equality dispatcher, including complete finite graphs;
sampling is not a replacement for equality of whole maps.

The validator preserves the full inner Hom even when the outer finite codomain
has a known inventory. Scalar fallback uses the independently declared input type.
For a point input, full recovered endpoint types and values are constrained before
the application builder opens a new metavariable depth, then the original complete
Hom prefix is reused. Legacy internal-callable construction remains separate.
