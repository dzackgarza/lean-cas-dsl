## Generic kernel change

`completeNamedObjectPresentations` now uses the existing generic structure-field
exposure when an initial full typed comparison cannot determine fresh declaration
parameters. It repeats the full type and value comparison and still requires a
closed, typed reconstruction and the existing kernel equality check. Exposure
supplies no field value and chooses no dictionary.

`recordCompleteUniversalObject` performs the analogous recovery for a missing
original object at an accepted limit or colimit declaration. It retains the full
apex, diagram, category bundle and declaration parameters. The recovered
application must equal the accepted presentation, and its apex must pass the
kernel check against the original object. All complete alternatives remain
visible; distinct accepted presentations are ambiguous. An unresolved original
object is rejected. No row name, coordinate representation or preferred route is
built into the algorithm.

Recovery occurs after actual retained computations and their original trace/data
paths. A cached packet, its positioned opaque occurrences and suppliers remain
authoritative computational inputs. A reconstructed formal presentation cannot
replace such a returned packet. The computed-callable endpoint path is unchanged.
