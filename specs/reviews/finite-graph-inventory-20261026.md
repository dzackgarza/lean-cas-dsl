# Explicit finite-graph inventories at actual endpoints

The released `finiteGraph` envelope permits an explicit point inventory when an
endpoint codec declines enumeration. Both callable validators previously rejected
that case before inspecting the supplied inventory. The fixed F9 execution exposed
this generic contract mismatch at a named modular endpoint.

The repair preserves every available actual inventory and every existing endpoint
error. Only a declined enumeration can use the explicit inventory, after checking
its distinct points against the actual public descriptor and its ordered parameters.
The complete graph must cover exactly those points, and its outputs retain the
existing independently typed codomain checks. Opaque or unsupported descriptors do
not acquire a shape from the requested formal apex.

Actual descriptor inspection bypasses a whole-descriptor association with the
formal construction. Actual inline representation parameters also precede equal-JSON
formal associations. An unresolved or opaque scalar parameter fails at that boundary;
it cannot borrow a different retained formal value. Nested descriptors recurse in
the same mode, while ordinary semantic parameters retain the existing complete
interface resolver. Known product-factor inventories remain exact.

These are data-framing checks. They establish no mathematical finiteness,
completeness, membership, inverse law or map law. Returned values and their opaque
ownership records are unchanged.
