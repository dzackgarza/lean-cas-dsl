## New code

The repair binds the original complete operand endpoint to a fresh declaration
field path, after reproducing its exact original point fragment. It retains the
complete ordered product child context independently of service-handle
allocation, including snapshot and copied-packet identity. The global context
comparison is reflexive for construction, lift and proof provenance; restricted
operation use has a separate conservative guard.

Current product comparisons are assembled only from independently checked
component comparisons. Their runtime directions use existing `typedMap`,
`mediator`, `compose`, and registered `limitLeg` encodings, retaining original
component map packets and suppliers. Source and target diagrams use their
respective full endpoints. Actual graphs still require actual point inventories.
No endpoint is selected from equal carriers, JSON, native parent objects, row
order or a formal answer. Scope-local normalization must reject conflicting
whole comparisons before copied-data lookup, while original selection context
and exact component occurrences remain retained.

The invocation domain, source, target, and argument are prepared together.
The original trace supplies the ordered product mediator; its children are
framed at their independently retained semantic and actual endpoints. The
complete mediator is checked against the original point composed with the
domain inverse and target forward comparison. The original closed product
array remains point data, and every complete prepared packet is retained as
a Wire for nested service reuse. A same-data framing copy is not exposed as
a competing input occurrence.

Ordinary framing now retains its exact original input, source, target, and
category context. A changed direct frame is prepared only after the old
producer reconstructs the complete original packet, owners and context.
Later service-handle allocation is checked through its exact occurrence
graph separately from semantic context identity. Proof snapshots preserve
the framing record. New actual replies retain their existing actual point or
map endpoint interface and do not inherit an old recipe's framing origin.
The kernel does not infer an original frame for an arbitrary opaque,
composed, or transported packet. If such a packet needs a new comparison
and has no independently retained framing boundary, that use remains an
explicit computation gap.

The argument builder consumes the original complete endpoint Wires supplied by
those checked field and product occurrences. It validates their full objects,
category dictionaries, point Hom, positioned ownership and exact dependency
graphs directly. It does not re-read a formal endpoint expression and require
that fresh selection to recover the same independent computational presentation.
That redundant re-selection discarded refinement history in the original
primitive case and the selected nonidentity presentation in the product control.
Original-to-normalized context, saved framing origin/replay, whole-product
conflicts and distinct child-history ambiguity checks remain unchanged.
